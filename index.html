Modelo de Datos Consolidado y Revisión de Relaciones

Arquitectura del Modelo Estrella / Constelación de Hechos (Anti-Duplicación)
Separación estricta entre Tablas de Hechos, Dimensiones Maestras, Tablas Operativas e Indicadores Calculados
1. Conciliación de Ventas (Sin Duplicar)

Base Prod. y Vol. (266,041 filas) y Base a la fecha (266,096 filas) comparten exactamente los mismos 266,041 registros de bebidas (96,607.03 HL). El motor los unifica por clave compuesta (Año/Mes + Cliente + Producto + Vendedor) sin duplicar ni un solo hectolitro, incorporando las 55 filas exclusivas de POP.

2. Dimensiones Maestras (1:N Garantizado)

Base Portfolio (1,673 SKUs únicos), Medida Tiempo (24 períodos), DetallePersonal (16 códigos), Canal MKT (19 canales) y Subcanales Mkt (69 subcanales) tienen unicidad primaria verificada para impedir la multiplicación de filas al cruzar.

3. Hechos de Granularidad Específica

Base Obj. (591,870 filas), Base CNC (25,893 filas desduplicadas), Base Eficiencia (40,317 filas), Base MXPDV (21,338 filas) y Base Rechazos (5,803 filas) se consultan respetando su propia granularidad sin cruzar muchos-a-muchos contra ventas.
